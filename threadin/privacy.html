ThreadIn Privacy Policy

Last updated: April 29, 2026

ThreadIn is a Chrome extension that helps users learn English from online comments. It can translate comments, explain slang and tone, save vocabulary, translate selected text, translate YouTube subtitles, and generate reply drafts.

ThreadIn runs locally in your browser. It does not require a ThreadIn account or login.

Information ThreadIn Uses

ThreadIn may use the following information to provide its features.

Website Content

ThreadIn reads visible content on supported websites, such as comments, posts, subtitles, and text you select on the page.

This content is used only to provide translation, explanation, vocabulary extraction, subtitle translation, and reply generation features.

Website URL

ThreadIn reads the current page URL to check whether the website is supported, keep the side panel in sync, and save the source page for your learning records.

API Key

If you choose to use AI features, you need to provide your own OpenRouter API key.

Your API key is saved in your browser storage. ThreadIn does not operate its own server and does not collect your API key.

Learning Records

ThreadIn may save vocabulary, slang, saved comments, reply drafts, subtitle settings, language settings, theme settings, and other preferences in your browser storage.

These records are stored locally on your device.

How Information Is Used

ThreadIn uses information only for its single purpose:

To help users understand online comments, learn English, save useful vocabulary, and draft natural replies.

ThreadIn does not use your information for advertising, tracking, profiling, credit decisions, or unrelated purposes.

AI Provider Requests

ThreadIn does not run its own backend server.

When you use AI features, ThreadIn sends the necessary text to the AI provider configured in the extension, such as OpenRouter. This may include comments, subtitles, selected text, or your reply draft.

These requests are made only when needed to provide the feature you use.

Your use of the AI provider may also be subject to that provider's privacy policy and terms.

Data Storage

ThreadIn stores settings and learning records locally in your browser.

  • API key
  • Language preferences
  • Theme preferences
  • Vocabulary
  • Slang records
  • Saved comments
  • Reply drafts
  • Subtitle preferences
  • Source page URLs for saved learning records

You can remove this data by clearing the extension's storage or uninstalling the extension.

Data Sharing

ThreadIn does not sell your data.

ThreadIn does not transfer your data to third parties for advertising, tracking, or unrelated purposes.

ThreadIn only sends text to the AI provider you configure when needed for translation, explanation, vocabulary extraction, subtitle translation, or reply generation.

Remote Code

ThreadIn does not load or execute remote code.

The extension code is packaged with the extension. Network requests are used only to call the AI provider configured by the user or to read supported page data needed for extension features.

Children's Privacy

ThreadIn is not designed for children under 13.

ThreadIn does not knowingly collect personal information from children.

Changes to This Policy

This privacy policy may be updated from time to time.

If the policy changes, the updated version will be published with a new "Last updated" date.
